## 卷积和

$$
y[n] = (x * h)[n] = \sum_{k=-\infty}^{\infty} x[k]\, h[n-k].
$$

> [!theorem] 卷积定理
> 时域卷积对应频域相乘：$\mathcal F\{x * h\} = X(\omega)\, H(\omega)$。

> [!proof]
> 把卷积和代入傅里叶变换的定义，交换求和顺序，令 $m = n-k$ 即得。

## 和傅里叶级数的关系

复指数 $e^{j\omega n}$ 是 LTI 系统的特征函数，所以把输入分解成复指数之和（见 [[傅里叶级数]]）就能逐个频率分析系统。下面这个演示展示了方波的傅里叶级数部分和：

## 代码

```python
import numpy as np
h = 0.5 ** np.arange(20)          # 冲激响应
x = np.r_[np.ones(10), np.zeros(10)]
y = np.convolve(x, h)[: len(x)]   # 输出
```
