复指数的包络

Lecture 2 后半段图里那两条把波形夹住的虚线，在不同场合指的不是同一件事。下面三个实验各对应一种，左边是复平面，右边是时域波形。

复指数（旋转的指针） 实部，也就是真正画出来的信号 包络 / 虚线曲线
实验 1 · 连续时间

阻尼正弦的包络就是复指数的模

信号 x(t) = Re{C est} = |C| eσt cos(ωt + θ)。左图指针的长度是 |C|eσt，它在实轴上的投影就是 x(t)。拖动时间，看右图中琥珀色竖线的高度始终等于左图指针的长度。

复平面：C est 的螺旋轨迹
时域：实部与包络 ±|C|eσt，空心圆是波形与包络相切处

相切点（cos = ±1）不等于波形的峰值。σ < 0 时，每个峰都比相切点稍早一点出现，因为求导时多出一项 σeσtcos(·)。把 σ 调到 −0.4 看得最清楚。包络描述的是指针长度，不是“把峰连起来”。

实验 2 · 离散时间

C αn 的包络是 |α|n

写成 α = r ejΩ，每走一步就旋转 Ω、缩放 r。实部 rncos(Ωn) 被夹在 ±rn 之间。包络只在整数 n 上有定义，虚线只是为了看着方便。

复平面：αn 的各点
时域：Re{αn} 与包络 ±rn

选 −1 < α < 0 时，样本每步翻转符号，在包络内上下交替。连续时间的实指数做不到这一点，它对应离散时间能表示的最高频率 Ω = π。

实验 3 · 离散正弦上的虚线

这条虚线不是包络，不能用来判断周期

画离散正弦 cos(Ω0n) 时，常把连续的 cos(Ω0t) 用虚线画在样本后面。它只是穿过样本的一条曲线，不是信号本身的属性：周期可以和序列不同，而且穿过同一组样本的曲线不止一条。

样本 cos(Ω0n)，n = 0…40；竖线标出序列的一个周期

m = 3、N = 16 时，虚线周期是 16/3 ≈ 5.33，但序列要到 n = 16 才重复。勾选 Ω0 + 2π 后，另一条快得多的曲线也精确穿过每一个样本。这正是频率差 2π 无法区分的意思，也是后面混叠的来源。
