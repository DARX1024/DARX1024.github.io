多项式拟合与梯度下降

数据由 \(\sin(2\pi x)\) 加高斯噪声生成，再用 \(M\) 阶多项式去拟合：

\[ y = \sin(2\pi x) + \varepsilon,\qquad \varepsilon \sim \mathcal{N}(0,\sigma^2) \] \[ y(x,\boldsymbol{w}) = \sum_{j=0}^{M} w_j\,u^j \]

勾选特征缩放时 \(u = 2x-1\)，否则 \(u = x\)；\(\boldsymbol{\Phi}\) 是 \(N\times(M+1)\) 的设计矩阵，\(\Phi_{ij} = u_i^{\,j}\)。损失是带 L2 惩罚的均方误差，梯度按下式手写，没有用自动微分：

\[ \begin{aligned} E(\boldsymbol{w}) &= \frac{1}{2N}\,\lVert \boldsymbol{\Phi}\boldsymbol{w} - \boldsymbol{y} \rVert^2 + \frac{\lambda}{2}\,\lVert \boldsymbol{w} \rVert^2 \\ \nabla E(\boldsymbol{w}) &= \frac{1}{N}\,\boldsymbol{\Phi}^{\top}(\boldsymbol{\Phi}\boldsymbol{w} - \boldsymbol{y}) + \lambda\boldsymbol{w} \end{aligned} \]

怎么读这些图

过拟合：\(M=9\)、\(N=10\)、\(\lambda=0\) 时，10 个参数刚好能插值 10 个点，训练 RMSE ≈ 0，但曲线在样本之间剧烈振荡，测试 RMSE 远高于噪声 \(\sigma\)。模型拟合的是这一组噪声，而不是 sin。

两种克服方法：加 L2 惩罚（\(\ln\lambda\approx-18\) 时测试误差就明显下降，\(\lambda\) 再大又会欠拟合，测试曲线呈 U 形）；或者增加样本（\(N=100\) 时同样的 \(M=9\) 也很平滑）。

梯度下降为什么很难“过拟合”：损失是二次函数，梯度可以写成 \(\nabla E(\boldsymbol{w}) = \boldsymbol{A}\boldsymbol{w}-\boldsymbol{b}\)，Hessian 是常数矩阵

\[ \boldsymbol{A} = \frac{1}{N}\,\boldsymbol{\Phi}^{\top}\boldsymbol{\Phi} + \lambda\boldsymbol{I},\qquad \boldsymbol{b} = \frac{1}{N}\,\boldsymbol{\Phi}^{\top}\boldsymbol{y} \]

它的条件数 \(\kappa\) 极大（见顶部指标）。GD 的步长受最大特征值 \(L\) 限制：

\[ 0 < \eta < \frac{2}{L},\qquad L = \lambda_{\max}(\boldsymbol{A}),\qquad \kappa = \frac{\lambda_{\max}(\boldsymbol{A})}{\lambda_{\min}(\boldsymbol{A})} \]

于是沿最小特征方向收敛要约 \(\kappa\) 步。高频振荡模式恰好落在这些方向上，所以有限步的 GD 相当于早停，自带隐式正则化。可以看训练曲线里测试 RMSE 先降后升。关掉特征缩放，\(\kappa\) 会再大好几个数量级。

CG 在精确算术下 \(M+1\) 步收敛到 \(\boldsymbol{w}^\star\)；浮点下会多几步，但仍远快于 GD。
